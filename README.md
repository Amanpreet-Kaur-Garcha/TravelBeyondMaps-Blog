# TravelBeyondMaps – Interactive Travel Blog Web Application
TravelBeyondMaps is an interactive travel blog web application developed using HTML, CSS, and Vanilla JavaScript. The project focuses on dynamic frontend functionality, responsive UI design, and LocalStorage-based data persistence.

The application allows users to explore travel stories, view detailed blog pages, interact through likes and comments, and dynamically create blogs using a frontend-based content management system.

## Features
- Dynamic blog rendering using JavaScript
- Responsive blog grid layout
- Individual blog view pages
- Like system with persistent storage
- Comment system with add/delete functionality
- Category-based blog filtering
- Frontend authentication flow
- Create Blog modal with form validation
- Dynamic blog creation and deletion
- Toast notification system
- LocalStorage-based data persistence
- Modern responsive UI design
